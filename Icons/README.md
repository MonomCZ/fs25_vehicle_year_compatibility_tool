# Bundled icons

- `MAINicon.png` is the application/window icon and the default in-game icon
  for a newly created **Vehicle Years Compatibility Tool** addon. It is covered
  by the project licence.
- `ALTicon.png` is the optional easter-egg in-game icon. It was supplied by the
  project owner and contains third-party meme/logo imagery. It is **not**
  covered by the MIT licence. Do not redistribute the ALT icon separately or
  use it commercially without checking the original rights.
- `appicon.ico` is generated from `MAINicon.png` for the Windows executable.
